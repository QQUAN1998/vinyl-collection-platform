## 2026-07-19 TV 扫码登录大收藏同步修复

- 真机现象：手机扫码后提示“电视未确认，请重试”，TV 端停留在“等待手机确认登录”。
- 根因拆解：1 张唱片的小包可以通过代理确认；385 张收藏、4912 首曲目的完整同步包约 `622872` bytes，经过云托管代理时返回 `500`，TV 会话仍是 `pending`。直接请求 Aiforce TV 服务能确认成功，说明 QR、TV APK 和 Aiforce 确认接口本身没有坏；问题在小程序到云托管代理这段对大请求体不稳定。
- 后端修复：新增 `apps/api/src/http-body-parser.ts`，启动时关闭 Nest 默认 body parser，并显式注册 `2mb` 的 JSON / urlencoded body limit；远端 main 已通过 GitHub API 发布 `053b114 fix: allow large tv login payloads`。
- 小程序修复：`apps/miniprogram/services/tv-login-service.js` 的 TV 登录同步包改为每张唱片只携带前 `12` 首曲目预览，同时保留真实 `songCount`、封面、艺人、年份、价格、数量等 TV 展示和统计需要的字段。385 张同步包下降到约 `490187` bytes，线上 `proxy-confirm` 实测返回 `confirmed`。
